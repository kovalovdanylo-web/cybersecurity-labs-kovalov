Цей репозиторій містить виконані лабораторні роботи з курсу, присвяченого основам кібербезпеки, криптографії та захисту інформації.

Кожна лабораторна робота розташована в окремій директорії (lab01/, lab02/, тощо) і містить необхідні скрипти та інструкції (README.md всередині папки).

📋 Огляд Лабораторних Робіт

№           Назва роботи                            Ключові технології / Тема                           Файли

1   Аудит власної цифрової безпеки              Аналіз надійності паролів, перевірка витоків.       Python

2   Дослідження криптографічних хеш-функцій     SHA-256, колізії, застосування.                     Python

3   Реалізація симетричного шифрування          AES (режими роботи), тестування швидкості.          Python

4   Основи асиметричної криптографії            RSA або ECC, генерація ключів, ЕЦП.                 Python

5   Аналіз мережевого трафіку                   Перехоплення та аналіз пакетів (концептуально).     (Концепт)

6  Вразливість SQL-ін'єкції та захист           Flask, SQLite, прямі/параметризовані запити.        Python, Flask

7   Двоетапний захист файлу                     AES-256-GCM, LSB Стеганографія, Аналітика.          Python, PyCryptodome, PIL

🛠️ Вимоги та Налаштування

Більшість лабораторних робіт реалізовано на Python.

Загальні вимоги

Встановлений Python 3.

Використання віртуального середовища (рекомендовано).

Встановлення залежностей

Для запуску всіх робіт (особливо ЛР №6 та №7), встановіть необхідні бібліотеки:

# Для криптографії, стеганографії та аналітики (ЛР №7)
pip install pycryptodome Pillow numpy pandas matplotlib

# Для веб-додатку (ЛР №6)
pip install Flask


🚀 Інструкції з використання

Для запуску конкретної лабораторної роботи виконайте наступні кроки:

Перейдіть до потрібної директорії:

cd lab07


(замініть lab07 на номер потрібної роботи, наприклад, lab06).

Дотримуйтесь локальних інструкцій:

Прочитайте файл README.md всередині цієї директорії.

Запустіть основний скрипт, як зазначено в інструкції (наприклад, python3 stego_crypto.py або python3 app.py).
